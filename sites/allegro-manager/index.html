Allegro Manager

Hurtownie XML → Twoje oferty na Allegro

Własny, samodzielny system w stylu SkyShop / BaseLinker: panel administracyjny, który pobiera pliki XML polskich hurtowni, autoryzuje się z Allegro przez OAuth, masowo wystawia przedmioty i synchronizuje ceny oraz stany. PHP + SQLite — bez abonamentu, działa na Twoim hostingu.

Co potrafi panel

🔐 Autoryzacja OAuth jak SkyShop

Authorization Code z przekierowaniem do Allegro + Device Flow (kod na telefon). Automatyczne odświeżanie tokenów, środowisko produkcyjne i Sandbox.

📥 Import XML polskich hurtowni

Auto-wykrywanie formatu: IOF (Internet Offer Format), Ceneo XML i dowolne feedy z polskimi/angielskimi nazwami pól (nazwa, cena_brutto, EAN, stan…). Basic Auth, gzip, własne mapowanie pól JSON-em.

🧮 Marże i ceny

Osobna marża procentowa dla każdej hurtowni, przeliczanie netto→brutto z VAT, podgląd ceny końcowej przed wystawieniem.

🎯 Dopasowanie po EAN

Produkty łączone z katalogiem Allegro po kodzie GTIN/EAN — oferta dziedziczy zdjęcia i parametry produktu z katalogu.

🏷️ Masowe wystawianie

Oferty robocze (dokończysz w Allegro) albo od razu aktywne. Domyślny cennik dostawy, polityka zwrotów, reklamacje i gwarancja z Twojego konta.

🔄 Synchronizacja i cron

Panel pamięta wystawione oferty (baza SQLite) i aktualizuje ich ceny/stany wg świeżego importu — ręcznie jednym przyciskiem albo automatycznie przez cron hostingu. Produkt znika z feedu → stan 0.

🗄️ Baza SQLite

Produkty, hurtownie, rejestr ofert i logi w jednym pliku bazy (WAL, transakcje, indeksy). Zero konfiguracji, szybkie wyszukiwanie przy dziesiątkach tysięcy produktów, automatyczna migracja ze starszej wersji.

🛡️ Bezpieczeństwo

Logowanie hasłem (bcrypt), tokeny CSRF, limit prób logowania, rotowany token crona, dane i tokeny w katalogu zablokowanym przez .htaccess.

⚠️ Wymagania: panel to aplikacja PHP 7.4+ (PDO SQLite, cURL, XMLReader, SimpleXML — standard na polskich hostingach). Na hostingu statycznym (np. GitHub Pages) zobaczysz tylko tę stronę — wgraj folder na hosting z PHP (np. przez FTP) i otwórz panel/. Szczegóły w README.md. Do połączenia z Allegro potrzebujesz darmowej aplikacji z apps.developer.allegro.pl.
