    Klucze API

    Warstwy „Premium” i „Pogoda” działają po wklejeniu darmowego klucza od dostawcy (jak w Locus Pro). Klucze zapisują się tylko w Twojej przeglądarce.

    Chmura GitHub — konto i foldery POI

    Załóż konto (login + hasło), a Twoje foldery punktów będą zapisywać się automatycznie w bazie poi-db tego repozytorium i będą dostępne z każdego urządzenia po zalogowaniu.

    Administrator — aktywuj chmurę dla wszystkich (właściciel repo)

    Wklej swój token GitHub (fine-grained, dostęp TYLKO do repo www1, uprawnienie Contents: Read and write) i kliknij Aktywuj. Token zostanie zapisany w formie zakodowanej w cloud/config.json na gałęzi poi-db — od tej chwili wszyscy użytkownicy zakładają konta samym loginem i hasłem. Uwaga: kodowanie chroni przed skanerami, nie przed człowiekiem — baza POI jest publiczna, a token musi być ograniczony do tego jednego repo.

    Zaawansowane — własny token GitHub

    Konta działają przez token aplikacji skonfigurowany przez właściciela repo (cloud-config.js). Możesz też użyć własnego tokena (fine-grained, Contents: write do www1) — ma pierwszeństwo i zostaje w tej przeglądarce.

    Dodaj własną mapę

    Podepnij dowolną usługę WMS (np. z Geoportalu, ISOK, geoportali wojewódzkich) albo serwer kafelków XYZ. Mapa trafi do kategorii „Moje mapy (własne)”.

    Offline — bufor map

    Bufor obejmuje aktywną mapę bazową i włączone nakładki. Pobieraj małe obszary — regulaminy dostawców kafelków zabraniają masowego zgrywania map; pełne mapy offline to zadanie wersji Android.
