Zgodnie z zasadami

Działa przez oficjalne Graph API Facebooka. Token i dane nie opuszczają Twojej przeglądarki.

Jak zdobyć token (2 minuty)

Otwórz Graph API Explorer

Wejdź na developers.facebook.com/tools/explorer i zaloguj się.

Wygeneruj token

Kliknij „Generate Access Token" i zaznacz uprawnienia pages_read_engagement oraz public_profile.

Wklej token wyżej

Skopiuj wartość z pola Access Token i wklej ją w polu „Token Graph API".

Wpisz nazwę strony i pobierz

Podaj adres fanpage'a i kliknij „Pobierz dane". Gotowe — dane i zdjęcia pojawią się poniżej.

Ważne — legalność i ograniczenia. To narzędzie korzysta wyłącznie z oficjalnego Graph API Facebooka i pobiera tylko publicznie dostępne dane stron (fanpage). Nie omija logowania, nie pobiera prywatnych profili osób ani treści chronionych. Ręczne „scrapowanie" HTML Facebooka łamie regulamin serwisu i grozi blokadą — dlatego świadomie go tu nie stosujemy. Odpowiadasz za zgodność wykorzystania danych z RODO i regulaminem Facebooka. Link typu /share/… jest prywatnym skrótem i wymaga zalogowania — podaj publiczną nazwę strony.
