Rozdział 4 · Gotowe wzorce dla typowych maszyn

Z tych kilku wzorców składa się 90 % programów małych maszyn. Zapis LAD jest tekstowy (--| |-- styk NO, --|/|-- styk NC, --( )-- cewka), obok — odpowiednik SCL. Przykładowe adresy dobrano pod 6 wejść / 4 wyjścia CPU 1211C.

Wzorce
  1. Start/stop z podtrzymaniem
  2. Nawrotnik silnika (lewo/prawo)
  3. Rozruch gwiazda–trójkąt
  4. Przenośnik z czujnikiem i licznikiem
  5. Pompa i zbiornik (dwa poziomy)
  6. Sygnał analogowy + alarmy
  7. Miganie lamp i sygnalizacja
  8. Sekwencja krokowa (automat stanów)
  9. Checklista uruchomienia maszyny

4.1Start/stop z podtrzymaniem — fundament wszystkiego

Przydział I/O: I0.0 START (NO), I0.1 STOP (NC!), I0.2 styk pomocniczy zabezpieczenia termicznego, Q0.0 stycznik silnika.

// Network 1 — samopodtrzymanie (uklad stycznikowy przeniesiony do PLC)
      START        STOP       TERMIK       SILNIK
    --|  |--+-----|  |-------|  |---------(   )--
   SILNIK   |
    --|  |--+
// STOP i TERMIK sa fizycznie NC, wiec w programie czytamy je stykiem NO:
// przerwanie przewodu = utrata "1" = natychmiastowe zatrzymanie (fail-safe).
// SCL — to samo:
"Silnik" := ( "Start" OR "Silnik" ) AND "Stop_NC" AND "Termik_NC";

Alternatywa: przerzutnik SR (S=Start, R1=Stop) — priorytet Reset gwarantuje, że STOP zawsze wygrywa.

4.2Nawrotnik silnika (lewo/prawo)

I0.0 START-P, I0.3 START-L, I0.1 STOP (NC), Q0.0 stycznik P, Q0.1 stycznik L.

// Network 1 — kierunek P: blokada krzyzowa przez wyjscie L i przycisk L
     START_P      STOP      SILNIK_L    START_L     SILNIK_P
    --|  |--+----|  |--------|/|----------|/|--------(   )--
   SILNIK_P |
    --|  |--+
// Network 2 — kierunek L: lustrzane odbicie (blokada przez SILNIK_P i START_P)
Blokada programowa to za mało Styczniki kierunkowe muszą mieć także blokadę mechaniczną i elektryczną (styki NC nawzajem w obwodach cewek). Zwarcie międzyfazowe przy sklejonym styku to pożar rozdzielnicy. Dodaj też przerwę czasową przy zmianie kierunku (TON 0,5–1 s).

4.3Rozruch gwiazda–trójkąt

Q0.0 stycznik główny, Q0.1 stycznik gwiazdy, Q0.2 stycznik trójkąta. Timer TON 5 s (czas rozruchu) + 50 ms przerwy na wygaszenie łuku.

// Po starcie: glowny + gwiazda. TON odmierza rozruch.
// Po T#5s: gwiazda odpada, po T#50ms zalacza sie trojkat.
IF #Praca THEN
    #tRozruch(IN := TRUE, PT := T#5s);
    #tPrzerwa(IN := #tRozruch.Q, PT := T#50ms);
    "StycznikGlowny" := TRUE;
    "StycznikGwiazda" := NOT #tRozruch.Q AND NOT "StycznikTrojkat";
    "StycznikTrojkat" := #tPrzerwa.Q  AND NOT "StycznikGwiazda";
ELSE
    #tRozruch(IN := FALSE, PT := T#5s);
    #tPrzerwa(IN := FALSE, PT := T#50ms);
    "StycznikGlowny"  := FALSE;
    "StycznikGwiazda" := FALSE;
    "StycznikTrojkat" := FALSE;
END_IF;

Styczniki Y i Δ dodatkowo blokuj mechanicznie. Uwaga: to zajmuje 3 z 4 wyjść 1211C.

4.4Przenośnik z czujnikiem i licznikiem sztuk

I0.2 czujnik optyczny, Q0.0 napęd taśmy. Licznik CTU zlicza produkty; po 24 szt. (karton pełny) taśma staje.

// Network 1: start/stop tasmy jak w 4.1, dodatkowo warunek "NOT KartonPelny"
// Network 2: licznik sztuk
        CZUJNIK          +-------+
    ----|P|--------------|CTU    |
                         |    QU |---- KartonPelny
   ResetKarton ----------|R      |
              24 --------|PV  CV |---- AktualnaLiczba (na HMI)
                         +-------+

Zbocze |P| przed CU jest obowiązkowe — inaczej wolny produkt przed czujnikiem policzy się raz na cykl programu. Rejestr przesuwny SHL taktowany enkoderem taśmy pozwala śledzić pozycję produktu (np. wyrzutnik braków 3 pozycje dalej).

4.5Pompa i zbiornik — dwa poziomy

I0.3 czujnik poziomu dolnego LSL, I0.4 czujnik poziomu górnego LSH, Q0.1 pompa napełniająca. Histereza między czujnikami eliminuje „kłapanie".

// Pompa startuje, gdy poziom spadnie ponizej LSL,
// pracuje az do osiagniecia LSH (samopodtrzymanie miedzy poziomami):
       LSL       LSH      Awaria
    --|/|---+----|/|-------|/|-------( POMPA )--
   POMPA    |
    --| |---+
// Sucho-bieg: TON 10 s — jesli pompa pracuje, a LSL nadal "0", alarm.

4.6Sygnał analogowy + alarmy (czujnik 0–10 V)

Czujnik ciśnienia 0–6 bar na kanale IW64. Skalowanie + dwa progi alarmowe:

// FC "Skalowanie" wywolywane w OB1:
#Norm      := NORM_X(MIN := 0, VALUE := %IW64, MAX := 27648);
"Cisnienie" := SCALE_X(MIN := 0.0, VALUE := #Norm, MAX := 6.0);   // [bar]

// alarmy z opoznieniem 2 s (eliminacja szpilek):
#tHi(IN := "Cisnienie" > 5.5, PT := T#2s);
"AlarmHi" := #tHi.Q;
#tLo(IN := "Cisnienie" < 0.5, PT := T#2s);
"AlarmLo" := #tLo.Q;
// przerwanie petli pradowej / zwarcie czujnika wykryjesz progiem < 0.2 V.

4.7Miganie lamp i sygnalizacja

Najprościej — bity zegarowe (rozdz. 2.7): lampa alarmu = Alarm AND M0.5 (1 Hz). Wzorzec pełnej kolumny sygnalizacyjnej:

  • Zielona ciągła — praca automatyczna: Q := Praca,
  • Żółta migająca — ostrzeżenie: Q := Ostrzezenie AND "Clock_1Hz",
  • Czerwona migająca do skwitowania, potem ciągła — klasyka ISA-18: miga, dopóki obsługa nie naciśnie „Kwituj", potem świeci ciągle aż do ustąpienia przyczyny.
"Niekwitowany" := ("Niekwitowany" OR #NoweZdarzenie) AND NOT "Kwituj";
"LampaCzerwona" := ("Niekwitowany" AND "Clock_1Hz") OR ("Alarm" AND NOT "Niekwitowany");

4.8Sekwencja krokowa — automat stanów

Każdy cykl maszyny (myjka, prasa, dozownik, mieszalnik) to sekwencja kroków. S7-1200 nie ma języka GRAPH, więc standardem jest zmienna kroku Int + CASE w SCL: 

CASE #Krok OF
    0:  // GOTOWOSC
        IF "Start" AND "OslonaZamknieta" THEN #Krok := 10; END_IF;
    10: // NAPELNIANIE
        "ZawarNapelniania" := TRUE;
        IF "PoziomOsiagniety" THEN
            "ZawarNapelniania" := FALSE;  #Krok := 20;
        END_IF;
    20: // MIESZANIE 30 s
        "Mieszadlo" := TRUE;
        #tKrok(IN := TRUE, PT := T#30s);
        IF #tKrok.Q THEN "Mieszadlo" := FALSE; #Krok := 30; END_IF;
    30: // OPROZNIANIE
        "ZawarSpustu" := TRUE;
        IF "ZbiornikPusty" THEN "ZawarSpustu" := FALSE; #Krok := 0; END_IF;
END_CASE;

// Timer #tKrok resetuj przy kazdej zmianie kroku; rownolegle prowadz
// timeout kroku (np. 2 min) -> alarm "sekwencja zawieszona".
IF #Krok <> #KrokPoprzedni THEN
    #tKrok(IN := FALSE, PT := T#0s);
    #KrokPoprzedni := #Krok;
END_IF;
  • Numeruj kroki co 10 — łatwo dodać krok pośredni.
  • Krok 0 = stan bezpieczny; awaria lub STOP zawsze wymusza #Krok := 0 i gasi wszystkie wyjścia sekwencji.
  • Zmienną kroku pokazuj na HMI — diagnostyka „dlaczego stoi" robi się natychmiastowa.

4.9Checklista uruchomienia każdej maszyny

  1. Lista I/O — spis wszystkich czujników/napędów z adresami i typem styku (NO/NC), zanim napiszesz pierwszą sieć.
  2. Obwód bezpieczeństwa sprzętowo — E-STOP przez przekaźnik bezpieczeństwa odcina styczniki; PLC tylko obserwuje jego styk pomocniczy.
  3. Test wejść — w Watch table sprawdź każde wejście fizycznie (naciśnij / zasłoń czujnik).
  4. Test wyjść bez napędów — wymuszaj wyjścia przy odłączonych obwodach mocy (bezpieczniki silnikowe wyjęte).
  5. Tryb ręczny przed automatem — najpierw jog każdego napędu z HMI/przycisków, dopiero potem sekwencja automatyczna.
  6. Symuluj awarie — wyciągnij czujnik w trakcie cyklu, otwórz osłonę, zdejmij fazę: maszyna ma stanąć bezpiecznie i zgłosić czytelny alarm.
  7. Zrób kopię projektu z datą i opisem wersji; wgraj program na kartę pamięci jako backup w szafie.
